# nanobot-XMFork

## 新增/优化功能

以下为本 Fork 相对于上游 0.4.2 的新增功能和优化。

### 附件集中管理

- 在 WebUI 设置中集中查看已托管附件和存储占用，支持手动删除、存储额度设置和孤儿附件清理。
- 根据会话及工作区中的引用关系回收文件，删除会话时清理不再被其他有效引用使用的附件。

### 上传限额配置

- 可通过 `channels.websocket.uploads` 配置普通附件和视频的数量、单文件大小、单次上传总量，以及暂存池的数量和容量。
- WebUI 按网关返回的实际限额校验上传内容并给出提示。

### 模型推理强度配置

- 每个模型预设可配置允许使用的推理强度档位和默认档位。
- 聊天中的推理强度滑杆只显示该模型允许的档位，便于匹配不同模型或 API 服务的支持范围。

### 聊天活动与工具调用详情

- 在已完成的回复下直接展开本轮活动记录，并与消息菜单中的活动入口保持同步。
- 每次工具调用可单独展开参数、结果和错误信息，便于查看执行过程。
- 优化推理内容的多行显示，保留不同工具调用各自的记录。

### 记忆库浏览

- WebUI 侧栏新增「记忆」入口，集中查看当前 Agent 的常驻记忆和 Wiki。
- 支持逐层展开 Markdown 目录，并在记忆库内打开文档中的内部链接。

### 外部 Markdown 记忆导入

- 支持导入以 UTF-8 编码保存的聊天记录或记忆 `.md` 原文，由 Dream 按现有记忆规则整理。
- 整理成功后归档原文，失败的原文保留供重试。
- 归档原文支持预览、单独删除和批量删除。

### Windows 本地启动

- 提供 `start-webui.cmd`，可双击启动 WebUI，自动准备本地 Python 环境并安装项目依赖。
- 将启动器使用的配置、工作区、虚拟环境和缓存集中存放在仓库的 `userdatas` 目录。
